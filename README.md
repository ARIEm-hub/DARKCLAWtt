# DARKCLAW — GitHub Pages

Все файлы лежат в корне репозитория — папки не нужны.

## Файлы
- `index.html`
- `style.css`
- `script.js`
- `darkclaw-logo.png`
- `ari-bg.png`

## GitHub Pages
1. Загрузить все 5 файлов в корень репозитория.
2. Открыть **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)**.
5. Сохранить.

## Защита изображений
На сайте отключены обычное контекстное меню, перетаскивание изображений, touch-callout и часть стандартных сочетаний клавиш для сохранения/просмотра исходника. Фотографии используются как CSS-background, а не как обычные кликабельные изображения.

Полностью запретить копирование изображения в открытом веб-сайте технически невозможно: браузер должен получить изображение, чтобы показать его. Скриншоты, DevTools и прямой доступ к публичному GitHub-репозиторию нельзя надежно заблокировать клиентским JavaScript.
